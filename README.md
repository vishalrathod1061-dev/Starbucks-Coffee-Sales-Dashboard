# Starbucks Coffee Sales Analytics Dashboard

## Project Overview

This project analyzes Starbucks coffee sales data using Microsoft Power BI. The dashboard helps understand sales performance, customer purchasing patterns, and product trends.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## Key Performance Indicators (KPIs)

* Total Sales
* Total Orders
* Total Units Sold
* Total Stores
* Average Order Value

## Key Features

* Sales performance analysis
* Product-wise sales analysis
* Store-wise sales analysis
* Time-based sales trends
* Interactive dashboard filters

## Project File

The Power BI dashboard is available in this repository as a `.pbix` file.

## Objective

To analyze sales data and generate meaningful insights that support business decision-making.
